# Contact Form Submission Test

## Goal
Navigate to a contact page, fill in the contact form with valid test data, submit it, and verify a success message appears.

## Starting URL
https://example.com

## Max Steps
15

## Success Criteria
- Find and navigate to the contact page
- Fill in all required form fields with appropriate test data
- Successfully submit the form
- Verify that a confirmation or success message is displayed

## Test Data Suggestions
- Name: "John Doe"
- Email: "test@example.com"
- Message: "This is a test message from the E2E testing framework"
